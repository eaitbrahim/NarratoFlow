# Qur'an corpus

The Tanzil text files (`quran-simple-clean.txt`, `quran-uthmani.txt`) are fetched, not committed:

    uv run python scripts/fetch_quran.py

Downloads are verified against pinned sha256 values. Terms: see `LICENSE-tanzil.txt`
(verbatim copy only, attribute the Tanzil Project, link to https://tanzil.net).
