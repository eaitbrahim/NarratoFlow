# Plan 4: Audio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** For an approved series whose scenes all have a sketch (or a text card), produce per part one mastered audio file and one timeline JSON:
- narration is the scene text spoken verbatim by the channel voice, with word timings;
- Qur'anic verses are a licensed, allow-listed Hafs reciter's per-ayah recordings, with word-segment timings when the reciter has them;
- the splice is loudness-matched with 400 ms buffers, marker SFX follow the stroke schedule (never under verses), there is no music, and the master is -14 LUFS;
- speech starts at 0 s.

Plan 5 (Render) consumes the timeline and nothing else from this plan.

**Architecture:**
- **Voice providers** sit behind a `SpeechProvider` Protocol. Paid (default) is ElevenLabs `with-timestamps` over REST. Character alignment is mapped onto the author's words. The free chain is edge-tts (WordBoundary events), then Piper (no timings).
- **Fallback.** A paid-provider failure re-voices the whole part with the next provider in the chain. The fallback is recorded in the timeline.
- **Timings.** Missing timings come from the CTC aligner (`align` extra). Without the aligner they are estimated and the timeline carries a WARN.
- **Recitation** comes from a committed reciter allow-list (`assets/reciters/index.toml`) that records each reciter's licence. Audio and word segments are downloaded once into `data_dir/reciters/` with httpx.
- **Audio math** is numpy in memory. Decode, loudness measurement and the master `loudnorm` go through the `ffmpeg` binary via `subprocess`.
- **Orchestration.** `audio/build.py` runs per part under the part's `SpendTracker`, seeded with what the part has already spent. The CLI adds `audio build`.

**Tech Stack:** Python 3.12, httpx (ElevenLabs, quran.com), numpy, the ffmpeg CLI (decode, `loudnorm`, FLAC), optional `edge-tts` (`tts-edge`), `piper-tts` (`tts-local`) and `ctc-forced-aligner` (`align`). **No new core dependency.** ffmpeg is already a runtime requirement for Plan 5's encoder and CI already installs it, so it is the one audio tool. pyloudnorm/soundfile would add Python deps for work ffmpeg's `loudnorm` does to the broadcast standard (EBU R128).

**Spec:** `docs/superpowers/specs/2026-11-10-sketch-library-pipeline-design.md`. This plan implements:
- §2.1 (voice fallback recorded);
- §2.2d (verbatim narration; no dead air; verse-opening precedence);
- §2.2e (real reciter, Hafs default, allow-list, licence, word-segment timing, splicing);
- §3 step 5;
- §4.1 (voice row);
- §4.6 (narration cached per project);
- §5.2 (spending limit, per part);
- the audio facts §5.3 and §6.2 need, which are recorded in the timeline for Plan 6;
- the §10 rule "no SFX or music under verses; music off by default".

## Global Constraints

- **Narration is the author's exact words [spec §2.2d].**
  - Only `scene.narration.tts_text or source_text` of NARRATION scenes is ever sent to a voice. `Part.hook_text`, `recap_text`, `teaser_text` and "Part N of M" are never spoken.
  - Before any spend, every `tts_text` passes `assert_skeleton_preserved(source_text, tts_text)` (`text/tashkeel/verify.py`). A mismatch raises `PlanningError` naming the scene.
  - Nothing rewrites text for the voice: no number expansion, no punctuation edits.
- **Verses are never voiced by TTS [spec §2.2e].**
  - VERSE scenes use only a reciter from the allow-list whose `riwaya` equals `channel.riwaya` (default `"hafs"`).
  - No allow-listed reciter, a riwaya mismatch, or a missing ayah raises `ReciterError` (a FAIL). There is no TTS fallback for a verse.
  - Recitations are resolved and downloaded **before** any paid TTS call of the part.
- **Licence per reciter.** Every reciter entry records `license`, `license_url`, `source`, `segments_source` and `checked` (date). Each part's timeline lists them for every ayah used.
- **No dead air at the start [owner].**
  - A part's first audible sample (narration or recitation) is at ≤ `FIRST_ONSET_MAX_MS = 100`. Leading silence of the first clip is trimmed to 0 ms.
  - The on-screen hook shows at 0 s (Plan 5).
- **Verse precedence and silence under verses.**
  - No SFX inside a verse scene's slot, which includes its buffers.
  - A part that opens with a verse therefore opens with the recitation and no SFX.
  - There is never any music: `background_music = true` raises `ChannelConfigError("no licensed music pack is bundled; set background_music = false")` before any spend.
- **Splicing [owner §2.2e].**
  - Loudness match: the narration clips of a part (one group) and each verse scene (one group each) are gained to `MATCH_TARGET_LUFS = -18.0`, clamped to ±`MAX_MATCH_GAIN_DB = 12.0`.
  - `VERSE_BUFFER_MS = 400` of silence at every narration↔verse boundary, never at the part start.
  - A `FADE_MS = 10` fade is applied at every clip edge.
- **Master:** two-pass ffmpeg `loudnorm` to `I=-14`, `TP=-1.0`, `LRA=11` with `linear=true`, at 48 kHz mono, written as FLAC.
  - Final integrated loudness off by more than ±1 LU adds a timeline WARN `loudness off target: <value> LUFS`. So does a true peak above -1.0 dBTP.
  - The publishing FAIL is Plan 6's job.
- **Fallback is recorded, never silent [spec §2.1, §7.3].**
  - Any `ProviderError` from the primary voice re-voices the **whole part** with the next voice in the chain, so there is one voice per part.
  - The timeline's `voice` records `fallback_from` and `fallback_reasons`, and the CLI prints a warning.
  - `BudgetExceededError` and `MissingApiKeyError` never trigger a fallback.
- **Spending:**
  - Every paid TTS call goes through `TrackedSpeechProvider`: `ensure_room` on `ceil(chars) / 1000 × prices.voice(provider, model)` before the call, and a charge after. A failed call charges nothing.
  - The limit is per part, and it spans stages. The tracker starts at `part.spent_usd`, which `sketch generate` and `audio build` both persist.
  - An unapproved series is refused.
  - Cached clips cost nothing.
- **Caching [spec §4.6].** TTS output is cached per project in `<series dir>/.cache/tts/` with `StageCache`. The key is `cache_key("tts", ADAPTER_VERSION, {provider, model, voice_id, text})`. Reciter downloads are cached under `settings.data_dir / "reciters" / <reciter_id>/`.
- **Secrets.** The ElevenLabs key is `Settings.voice_api_key` (`NARRATOFLOW_VOICE_API_KEY`), unwrapped only in the adapter. It is never logged or echoed: error messages carry the status and the provider's error code/status string, never the body.
- **Optional extras load lazily.** A missing `edge-tts`, `piper-tts` or `ctc-forced-aligner` raises a clean `ChannelConfigError` or `AlignerUnavailableError` naming the extra (`install the 'tts-edge' extra: uv sync --extra tts-edge`), never an `ImportError`.
- **Tests never touch the network, a model, or GPU.**
  - Providers are tested with `httpx.MockTransport`, and the extras with monkeypatched fake modules.
  - Audio fixtures are generated in code (numpy tones and gated noise). No `.wav` or `.mp3` goes in git; `*.wav` and `*.mp3` are git-ignored anyway.
  - Tests that run ffmpeg use the `ffmpeg_bin` fixture. It skips locally when ffmpeg is missing and **fails** when `CI` is set; CI installs ffmpeg.
  - CI has no Tanzil text, so verse tests build a `QuranCorpus` from `tests/fixtures/quran/`, which has 31:33.
- `subprocess` is called with an argument list and the absolute path from `shutil.which`, never `shell=True`. Each call has a timeout (`FFMPEG_TIMEOUT_S = 120`). A non-zero exit raises `AudioError` with the last 5 stderr lines.
- New errors in `errors.py`: `AudioError(NarratoFlowError)`, `ReciterError(AudioError)` and `AlignerUnavailableError(AudioError)`.
- Same tooling gate as Plans 1–3. Sources are pure ASCII with `\u` escapes.

## Review Focus

1. **`tts_text` drifted from the author's words** (hand-edited `series.json`, or digits like `1924` and Arabic-Indic `١٩٢٤`). Expected:
   - a skeleton mismatch is refused before any spend, naming the scene;
   - digits are sent unchanged, and a digit token still gets exactly one `WordTiming` from ElevenLabs character alignment.

   → Task 2 and Task 10 tests.
2. **A verse whose reciter cannot serve it.** This covers: the allow-list has no reciter for the channel's riwaya; the configured reciter is not allow-listed; the ayah is missing upstream (404). Expected: `ReciterError` before any TTS spend (the fake voice has 0 calls), naming `surah:ayah` and the reciter. → Task 6 and Task 10 tests.
3. **A free voice gives no word timings and the `align` extra is not installed** (Piper, or edge boundaries that don't map). Expected:
   - audio is still built;
   - the words are estimated proportionally inside the speech span, with `timing_source = "estimated"`;
   - one timeline WARN per scene, plus a single "install the 'align' extra" WARN;
   - no crash.

   → Task 2 and Task 8 tests.
4. **A very short part (one 1.5 s scene) with dense SFX.** Expected:
   - the master's true peak is ≤ -1.0 dBTP, so there is no clipping in the FLAC;
   - a LUFS off by more than 1 LU is a WARN, not a crash;
   - SFX hits stay spaced ≥ 250 ms apart.

   → Task 1 and Task 9 tests.
5. **Leading silence in the TTS or recitation file** (ElevenLabs about 100 ms, everyayah/quran.com mp3s 300–800 ms). Expected:
   - the first onset is at ≤ 100 ms, with word and segment timings shifted by the trimmed amount;
   - a part opening with a verse has no SFX before the verse ends.

   → Task 9 tests.

### Task 1: Audio I/O and loudness (ffmpeg)

**Files:**
- Create `audio/io.py`, `tests/fixtures/audio.py`, `tests/audio/__init__.py`, `tests/audio/conftest.py`, `tests/audio/test_io.py`.
- Modify `errors.py`.

**Interfaces — Produces:**
- `SAMPLE_RATE = 48_000`. All internal audio is a mono `np.ndarray` of `float32` at this rate.
- `require_ffmpeg() -> Path`. Uses `shutil.which("ffmpeg")`; when it is missing, raises `AudioError("ffmpeg not found; install it (brew install ffmpeg / apt install ffmpeg)")`.
- `decode(data: bytes) -> np.ndarray`: `ffmpeg -v error -i pipe:0 -f f32le -ac 1 -ar 48000 pipe:1`. Empty output raises `AudioError("audio decodes to no samples")`.
- `encode_flac(samples: np.ndarray, path: Path) -> None`. Writes s16 FLAC at 48 kHz atomically: a temp file in the same directory, then `os.replace`.
- `@dataclass(frozen=True) class Loudness: integrated_lufs: float | None; true_peak_dbtp: float; lra: float; threshold: float; offset: float`.
  - `integrated_lufs` is None when ffmpeg reports `-inf`, or when the clip is shorter than 400 ms (it is too short to gate).
- `measure(samples: np.ndarray) -> Loudness`. Runs `loudnorm=I=-14:TP=-1:LRA=11:print_format=json` into `-f null -` and parses the last `{...}` JSON block on stderr (`input_i`, `input_tp`, `input_lra`, `input_thresh`, `target_offset`).
- `master(samples: np.ndarray, *, target_lufs: float = -14.0, true_peak_dbtp: float = -1.0, lra: float = 11.0) -> tuple[np.ndarray, Loudness]`.
  - Pass 1 is `measure`.
  - Pass 2 is `loudnorm` with `measured_I/TP/LRA/thresh`, `offset`, `linear=true` and `-ar 48000`.
  - It returns the output and `measure(output)`.
  - An input with `integrated_lufs is None` is returned unchanged with its measurement.
- `trim_silence(samples: np.ndarray, *, threshold_dbfs: float = -45.0, keep_ms: int = 20, keep_lead_ms: int | None = None) -> tuple[np.ndarray, int]`.
  - Uses 10 ms RMS windows. It keeps `keep_ms` before the first and after the last window above the threshold; `keep_lead_ms` overrides the lead.
  - It returns `(trimmed, lead_removed_ms)`, which callers subtract from timings.
  - An all-silent clip returns `(empty array, 0)`.
- `fade(samples: np.ndarray, ms: int = 10) -> np.ndarray` applies a linear fade in and out. `apply_gain(samples: np.ndarray, db: float) -> np.ndarray`. `silence(ms: int) -> np.ndarray`. `ms_to_samples(ms: int) -> int`.
- Test fixtures in `tests/fixtures/audio.py`:
  - `tone(ms, hz=440, dbfs=-20, lead_ms=0)`;
  - `speechlike(words: int, word_ms=300, gap_ms=80, lead_ms=0, dbfs=-20, seed=0)`: gated band-limited noise;
  - `to_wav_bytes(samples)` (stdlib `wave`);
  - `to_mp3_bytes(samples)` (ffmpeg libmp3lame).
- The `ffmpeg_bin` fixture is described under Global Constraints.

### Task 2: Word-timing mapping and the timeline schema

**Files:** Create `audio/words.py` and `audio/timeline.py`. Tests: `tests/audio/test_words.py`, `tests/audio/test_timeline.py`.

**Interfaces — Produces:**
- `@dataclass(frozen=True) class TimedSpan: text: str; start_ms: int; end_ms: int`. This is one provider unit: a character (ElevenLabs), a word boundary (edge) or an aligner word.
- `tokens(text: str) -> list[str]`, which is `text.split()`. Narration words are whitespace tokens of the author's text.
- `norm_for_timing(s: str) -> str`: NFC, then `strip_diacritics`, then `casefold`, then every whitespace character and Unicode `P*`/`S*` character is dropped.
- `timings_from_spans(words: list[str], spans: Sequence[TimedSpan]) -> list[WordTiming] | None`. It returns None when the normalized texts disagree. The algorithm is not determined by the signature:

  ```
  W = concat(norm(w) for w in words), with each word's [a_i, b_i) range in W
  S = concat(norm(s.text) for s in spans), with each span's [c_j, d_j) range (empty spans are skipped)
  if W != S: return None
  word i: start = start_ms of the first span overlapping [a_i, b_i); end = end_ms of the last one
  a word normalizing to "" (e.g. a lone dash) gets start = end = the previous word's end (0 for the first)
  then make starts non-decreasing: start_i = max(start_i, start_{i-1}); end_i = max(end_i, start_i)
  ```

  The `WordTiming.text` values are the input `words`.
- `estimate_timings(words: list[str], onset_ms: int, offset_ms: int) -> list[WordTiming]`. Splits `[onset, offset]` in proportion to `max(1, len(norm_for_timing(w)))`. Integer ms come from cumulative rounding, so the last word ends exactly at `offset_ms`.
- `shift(words: list[WordTiming], delta_ms: int, *, limit_ms: int) -> list[WordTiming]`. Adds `delta_ms` and clamps to `[0, limit_ms]`.
- `audio/timeline.py` holds the schema Plan 5 consumes. Every model has `ConfigDict(extra="forbid")`, and every ms field is `int >= 0` on the part clock.

  ```
  class TimingSource(StrEnum): PROVIDER="provider"; ALIGNED="aligned"; ESTIMATED="estimated";
      SEGMENTS="segments"; AYAH="ayah"   # AYAH: no segments, reveal each whole ayah at its start
  class AyahTiming: surah: int; ayah: int; start_ms; end_ms; words: list[WordTiming]   # Uthmani display words; [] when AYAH
  class SceneTiming: scene_id: str; kind: SceneKind; start_ms; end_ms; speech_start_ms; speech_end_ms;
      words: list[WordTiming]           # NARRATION: caption tokens (caption_text or source_text); VERSE: []
      timing_source: TimingSource; ayat: list[AyahTiming] = []
      draw_start_ms: int | None = None; draw_end_ms: int | None = None   # None: no strokes (verse, text card)
  class SfxHit: scene_id: str; stroke_index: int; at_ms; duration_ms: int (gt 0); asset_id: str; gain_db: float
  class VoiceUsed: provider: str; model: str; voice_id: str; fallback_from: str | None = None; fallback_reasons: list[str] = []
  class RecitationUsed: reciter_id: str; name: str; riwaya: str; license: str; license_url: str; source: str;
      segments_source: str | None; ayat: list[str]   # "31:33"
  class AssetUse: kind: Literal["sfx"]; asset_id: str; source: str; license: str; attribution: str = ""
  class PartTimeline: schema_version: Literal[1] = 1; series_title: str; channel_slug: str; part_index: int; part_count: int;
      audio_file: str                     # bare file name next to the timeline, e.g. "part-01.flac"
      sample_rate: Literal[48000] = 48000; duration_ms: int; integrated_lufs: float | None; true_peak_dbtp: float;
      scenes: list[SceneTiming] (min 1); sfx: list[SfxHit]; voice: VoiceUsed | None   # None: verse-only part
      recitations: list[RecitationUsed]; assets: list[AssetUse]; spent_usd: Decimal; cost_estimated: bool; warnings: list[str]
  ```

  - `PartTimeline` validators. Violating any of these raises `ValueError`:
    - `scenes[0].start_ms == 0`;
    - each scene's `end_ms` equals the next scene's `start_ms`, and the last one equals `duration_ms`;
    - `start <= speech_start <= speech_end <= end`;
    - words are inside the speech span and non-decreasing;
    - draw times lie inside the slot;
    - `ayat` only on VERSE scenes, and inside the scene;
    - `sfx` is sorted by `at_ms`, and no hit overlaps any VERSE scene slot;
    - `audio_file` has no path separator.
  - `PartTimeline.save(path)` is atomic. `PartTimeline.load(path)` raises `AudioError` on an unreadable, invalid or unknown-version file.

### Task 3: Speech provider protocol and the ElevenLabs adapter

**Files:**
- Replace `tts/__init__.py`. Create `tts/elevenlabs.py`.
- Modify `interfaces.py`: remove `TTSEngine` and `Aligner` (nothing imports them) and re-export `SpeechProvider` from `tts` and `Aligner` from `align`.
- Tests: `tests/tts/__init__.py`, `tests/tts/test_elevenlabs.py`.

**Interfaces — Produces:**
- `@dataclass(frozen=True) class SpeechRequest: text: str; voice_id: str; language: Language`
- `@dataclass(frozen=True) class Speech: audio: bytes; spans: tuple[TimedSpan, ...]; provider: str; model: str; billed_chars: int | None`. An empty `spans` means the provider gave no timings. `billed_chars` is None when the provider reports no count.
- `class SpeechProvider(Protocol): name: str; model: str; def synthesize(self, req: SpeechRequest) -> Speech: ...`
- `@dataclass(frozen=True) class VoiceChoice: provider: SpeechProvider; voice_id: str`
- `ElevenLabsProvider(api_key: SecretStr, model: str, http: httpx.Client | None = None)` with `name = "elevenlabs"`:
  - **Request:** `POST https://api.elevenlabs.io/v1/text-to-speech/{voice_id}/with-timestamps?output_format=mp3_44100_128`, with header `xi-api-key` and JSON `{"text": req.text, "model_id": model}`. The timeout is 120 s.
  - **Voice id:** must match `^[A-Za-z0-9]{8,64}$`, else `ChannelConfigError`. This prevents path injection.
  - **Response:** reads `audio_base64` (validated base64 and non-empty) and `alignment.characters`, `character_start_times_seconds` and `character_end_times_seconds`.
    - Spans come from `alignment`, **not** `normalized_alignment`, because `alignment` is aligned to the characters sent, which are the author's.
    - Arrays of unequal length raise `ProviderError`. A null `alignment` gives `spans=()`.
    - Seconds become ms with `round(x * 1000)`.
  - **Billing:** `billed_chars` comes from the documented character-count response header when present, else None.
  - **Errors:**
    - 401/403 → `ProviderError("ElevenLabs rejected the API key (HTTP 401)")`;
    - 429 → `ProviderError("ElevenLabs rate limit (HTTP 429)")`;
    - any other non-2xx → status plus `detail.status` (≤ 80 chars, scrubbed of the key);
    - timeout and connect errors → `ProviderError`.
  - **Verify the current endpoint, response field names and the character-count header** against the ElevenLabs API reference with WebFetch before coding. Record the URL and date in the module docstring, as `images/openai_images.py` does.

  ```

  NARRATION slot: speech at t + buffer; slot end = max(speech_end + INTER_SCENE_GAP_MS, t + scene.min_duration_ms)
  draw window (narration scenes with strokes): [slot start, slot start + round(scene.draw_fraction * slot length)]
  ```

  - **Loudness match.**

Scenes with no strokes entry (text cards) get none.

  - **Warnings** come from the off-target check (Global Constraints) and are merged with the narration and verse warnings.
